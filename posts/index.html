代理浅谈之内网渗透

前言

代理隧道是内网渗透测试中常用的技术手段，它允许攻击者通过一个已受控的外网服务器来访问内网中的其他设备。在渗透测试的后渗透阶段，攻击者通常无法直接从外网访问内网资源。这时，通过设置端口转发或搭建代理服务器，如Socks代理，可以构建一个通道，使得攻击者能够穿透网络边界，进而横向移动到内网的其他主机。

0、代理（PROXY）

概念：委托人

使用场景：加强隐私，保护数据，绕过 限制

Proxy（代理）是一种网络技术，它允许一个客户端通过另一个服务器（代理服务器）来访问互联网。代理服务器充当客户端和目标服务器之间的中间人，负责转发请求和响应。这种技术通常用于提高安全性、提高性能、绕过地理限制等目的。（来源于讯飞星火回答）

  • 举个栗子

    • 正好最近在换房子，就拿求租来举例

  • 类型

  • 正向代理：正向代理代理的是客户端，客户发送请求给到代理服务器，代理服务器代替客户把请求发送给服务器。（此时真实的客户端是匿名的）

    ![正向代理](F:/原E盘/迅雷下载/web security study note/内网渗透中代理细谈/正向代理.png)

  • 反向代理：代理的是服务端，客户端发送请求到代理服务器，代理服务器将收集到的请求分发给后面的服务器，对应的服务器处理完将结果返回代理服务器，代理再将结果给到客户端。（此时真实的服务器是匿名的）

![image-20240514192420883](F:/原E盘/迅雷下载/web security study note/内网渗透中代理细谈/反向代理.png)

2、SOCKS代理

SOCKS代理（来自维基百科）：

SOCKS是一种通过代理服务器在客户端和服务器之间交换网络数据包的Internet 协议。SOCKS5可选择提供身份验证，因此只有授权用户才能访问服务器。实际上，SOCKS 服务器将 TCP 连接代理到任意 IP 地址，并提供转发 UDP 数据包的方法。 SOCKS 服务器接受 TCP 端口 1080 上传入的客户端连接，如RFC 1928中所定义。

  • 工作原理图

  • SOCKS4 VS SOCKS5

    • 5：支持TCP,UDP协议，DNS查询，p2p共享，可进行身份验证

3、HTTP vs SOCKS

3.1 支持的协议

HTTP代理：仅支持HTTP/HTTPS协议传输、

SOCKS4代理：TCP：telnet，http，ftp

SOCKS5代理：支持TCP，UDP，DNS，POP3，P2P共享等

另外SOCKS代理不支持ICMP协议（工作在第三层），无法使用ping命令。

3.2 传递流量的不同方式

  • SOCKS只是简单的传递流量，HTTP代理仍然是中间人

  • HTTP代理工作在应用层，SOCKS代理工作在会话层。

总结

HTTP代理适合web端访问

SOCKS的代理支持的协议和试用范围广。

遗留的问题
  • SOCKS4和SOCKS5支持的tcp和udp协议没进行细的测试
